| Finding | Pass condition | If it fails |
|---|---|---|
| Directed data with media subscribe disabled | Companion receives targeted packets holding `can_subscribe: false` for media, per ADR-02 | **Stop.** ADR-02 explicitly forbids silently widening the grant. | Authenticated sender identity on received packets | SDK exposes sender identity and current SID per packet | **Stop.** The "controller is actual participant" invariant has no independent enforcement without it, and T04/T06 become untestable. Architecture revision, not a workaround |
